# Security policy

Please report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository. If that feature is unavailable, contact the maintainer privately through the address on the GitHub profile.

Do not open a public issue containing credentials, signing keys, session cookies, email content, internal hostnames, or SMTP diagnostic transcripts. Include the affected version, deployment topology, reproduction steps, and impact. You can expect an initial acknowledgement within seven days.

Only the latest release and the current `main` branch receive security fixes.
